This page tracks every PLFA declaration, theorem, and exercise in PLFH against
the current experimental Dependent Haskell compiler
([`Tritlo/ghc`, branch `dependent-haskell`](https://github.com/Tritlo/ghc/tree/dependent-haskell)).

- **Compiler & HaskLib:** GHC `10.1.20261115.1` (`Tritlo/ghc`, branch `dependent-haskell`, Wave 4 Track A preview [`c5dbff62fb`](https://github.com/Tritlo/ghc/tree/dependent-haskell) merged atop Wave 2 4-lane consolidated `bce571b213` and Wave 1 `186670b0b9`: Proposal `#378` `-XDependentTypes` umbrella bundle, default-on source equations, shared-type `foreach`/`forall`/`exists`/`some` telescopes, Unicode `∏`, verified at `-O0`, `-O2`, native `.hi`, and `-fno-code`) + `HaskLib.Nat` (`Nat(..)`, `type (+)`, `eqSize`/`eqSizeRefl`, decimal literals) and `HaskLib.rewrite`.
- **Verification mode:** Native `-O0 -fomit-interface-pragmas -fno-write-if-simplified-core -dcore-lint -dstg-lint` across all 34 modules, automated **`.hi` interface soundness audit** (`scripts/audit_ifaces.py`), **10 negative controls**, executable **runtime smoke test** (`clients/PLFH/RuntimeSmokeTest.hs`, 166 `[RUN-OK]` checks), **41 fixed regressions**, and **13 open compiler-gap reproducers**.
- **Proof discipline:** Zero typed holes, zero `-fdefer-type-errors`, zero `undefined`/`error`, zero circular bindings, zero `unsafeCoerce`, zero silently quantified function type variables in `.hi` interfaces.
- **Policy on gaps:** Avoid workarounds; mark unsupported items `[WIP NOTICE]` and maintain a minimal standalone reproducer under [`reproducers/`](https://github.com/Tritlo/PLFH/tree/main/reproducers).
